# SALURA logo

**Nota-chat.** A receipt (nota) with a torn top edge, and its bottom-left corner is a chat tail. It shows what SALURA does: a WhatsApp chat goes in, a validated order and invoice come out.

Everything here is generated by [`build_logo.py`](build_logo.py). Change the geometry there, never by hand, then run:

```bash
pip install cairosvg fonttools brotli pillow
python3 docs/brand/build_logo.py
```

It rewrites the masters in this folder and the web icons in `apps/web/public/`. If you change `MARK_SMALL`, copy it into `apps/web/src/components/brand/logo.tsx` too.

## Files

| File | Use |
|---|---|
| `salura-symbol.svg` | Primary mark in green, for 48 px and up |
| `salura-symbol-small.svg` | Small-size cut (two bigger teeth, thicker lines), up to 48 px |
| `salura-symbol-black.svg` / `-white.svg` | One-colour versions, for print, stamps and dark backgrounds |
| `salura-horizontal.svg` (+ `-white`, `-black`) | Main lockup: mark plus the SALURA wordmark |
| `salura-stacked.svg` (+ `-white`) | Square spaces: profile pictures, slides |
| `salura-app-icon.svg` | White mark on a green tile (512 px source for app icons) |
| `logo-concepts/` | The explored concepts, kept for reference |

In the app (`apps/web/public/`):

- `favicon.svg`
- `favicon.ico` (16/32/48)
- `apple-touch-icon.png` (180, full bleed)
- `icons/icon-{192,512}.png`
- `icons/icon-maskable-{192,512}.png`
- `manifest.webmanifest`
- `sw.js`

The React components are `Logo` (the tile) and `LogoMark` (the bare mark, takes the current text colour) in `src/components/brand/logo.tsx`.

## Colour

| | HEX | RGB |
|---|---|---|
| Primary green (`--primary`) | `#17603A` | 23 96 58 |
| Strong green (`--primary-strong`) | `#0E3F25` | 14 63 37 |
| Ink, for the wordmark (`--ink`) | `#111813` | 17 24 19 |

On green or dark backgrounds, use the white version. Never place the green mark on the strong green.

## Wordmark

The wordmark is "SALURA" in Plus Jakarta Sans Bold (SIL Open Font License), converted to outlines with +2 % tracking, so the SVGs need no font installed. In the console the name is live text in the same font.

## Rules

- **Clear space:** keep at least the height of one receipt tooth around the mark (about 10 % of the mark's height).
- **Minimum size:** 16 px for the small cut. For the full mark, 48 px or 12 mm. For the horizontal lockup, 96 px wide.
- **Don't:**
  - stretch, rotate or outline the mark
  - add shadows or gradients to it
  - recolour it outside the palette above
  - move the chat tail to another corner
  - remove the torn edge
- **Trademark:** not cleared. Run a trademark and reverse-image search before registering it.
